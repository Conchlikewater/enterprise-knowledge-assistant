# RAG V1 Offline Evaluation

This directory contains a synthetic, reproducible evaluation for the complete
local RAG pipeline. It requires no API key and sends no data to an external
provider.

## Corpus

The tracked corpus contains:

- 10 synthetic policy documents
- 6 UTF-8 TXT files
- 4 text-based PDFs
- 2 multi-page PDFs

`corpus_sources.json` is the canonical source. The files in `documents/` are
generated by `scripts/build_evaluation_corpus.py`.

## Questions

`questions.json` contains exactly 20 questions:

- 10 direct-answer questions
- 4 questions requiring multiple chunks
- 2 document-scope isolation questions
- 4 unanswerable questions

Direct and multi-chunk questions search the full corpus, so Top-5 source
accuracy measures ranking quality rather than relying on a single-document
filter. Scope-isolation questions deliberately restrict the selected corpus.

## Offline provider

The evaluator uses a deterministic hashing-based lexical embedding provider.
It exercises the production parsing, chunking, SQLite, Qdrant, retrieval,
answer, citation, and deletion code without cloud cost. It is not intended to
estimate the semantic quality of the configured OpenAI model.

The unanswerable threshold of `0.25` was selected after recording the initial
bad case at `0.2289`. This threshold applies only to the offline evaluator and
does not silently change production retrieval behavior.

## Quality gates

The evaluation fails unless all of these conditions hold:

- all 10 documents ingest and produce non-empty chunks
- expected sources appear in Top-5 for at least 80% of answerable questions
- all four multi-chunk questions retrieve at least two expected chunks
- both scope-isolation questions return no out-of-scope result
- all unanswerable questions return no evidence or citations
- every citation maps to an actual retrieved chunk
- expected PDF page metadata is present
- deleting a document removes its file, record, and vectors

Run the evaluation from the project directory:

```powershell
.\.venv\Scripts\python.exe scripts\run_evaluation.py
```

The latest verified machine-readable result is stored in
`evaluation/latest_report.json`.
