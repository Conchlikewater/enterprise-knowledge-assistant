# R7 自动构图独立实验 v1（2026-09-10）

用户已批准继续实现自动构图。此文件是新增实验范围，不回写已完成的人工图预注册及结果。

## 本版输入和能力边界

- 对44份已审核资料的课程信息/先修结构Chunk调用独立抽取Provider；不读取100题、答案、
  Gold路径或人工79边作为模型提示。所有来源使用统一结构块规则，不按检索得分选材料。
- 当前首页文本经过人工清洗和事实重建。因此本版只能证明**从审核过的结构文本自动构图**，
  不能宣传原始PDF全自动抽取、OCR或全605页自由文本关系发现。这是输入预处理的限制。
- 抽取REQUIRES、HAS_CREDIT、OFFERED_IN及明确适用专业的BELONGS_TO；目录归属不等于
  明确适用专业。只构建来源隔离的对象提及，不按同名自动合并课程，不生成跨文档路径。
- Chunk的document_id、页码、哈希由程序附加；模型不能提供或覆盖来源。每条关系须有
  当前Chunk中逐字存在的短支持片段，且对象值出现在支持片段中。引用存在不证明语义正确。
- 无先修、空栏、无法判断、冲突分别处理；空关系列表不是“明确无先修”。禁止创建None课程。
- 文本是数据，不是指令；不提供文件、网络、Shell工具，模型只返回受限JSON。

## 冻结评测办法（真实抽取前）

1. 按source_id排序，前4个来源为开发/接口冒烟，剩余40个为本版抽取评审集。
   不用已看过的100题做新的独立检索效果证明；本版首先评测抽取质量。
2. 记录JSON合规率、程序证据校验拒绝数、关系去重数、逐来源关系数、token/耗时/费用。
3. 旧79条人工边只是非穷尽参考：可报告其可比部分的覆盖率，不能把额外抽取都当假阳性，
   也不能以79作全语料Recall分母。新关系须独立人工审核支持性、主体、方向和对象粒度。
4. Precision仅在全部已审核输出上计算，并同时披露审核覆盖率；未审关系不算正确。
   Recall仅在另行穷尽标注的来源/字段子集上计算；没有穷尽标注则标为未测。
5. 暂定“可进入后续实验”的门槛：最终JSON/Schema合规100%、程序来源绑定100%、
   人工审核覆盖100%、审核关系Precision至少95%，所有身份误合并为0；任何缺项不通过。
   这是后续评审资格，不是接入app授权，不要求最终结果必须正向。

## 实现顺序与预算

先实现严格Schema、证据校验、稳定ID、去重和Fake测试，再做4来源真实冒烟。
模型/API能力与价格在首次真实调用前核验，冻结模型、提示哈希、输出上限和调用计划。
每Chunk一次请求，SDK不自动重试；仅兼容外围Markdown JSON围栏，不做猜测式JSON修复。
遇失败保留安全错误类型/请求收据，不重新执行已成功部分以消耗额度。
必要调用计入用户本次累计人民币10元上限；现已知消费约0.00718786美元，须保留换算余量。
